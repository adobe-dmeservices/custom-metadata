# How to use these examples as remote Views

When you make a new Tab, you can have that Tab display a local or remote View. Remote Views require a URL that resolves to a properly formatted JSON file. This folder contains all of the example Views that are included in Custom Metadata. 

To use, browse in Github to the View you want to use, then click the Raw button to expose the raw JSON. Copy the URL in the address bar of your browser and paste it into the Location field of your Tab. Save and close in Custom Metadata and your remote view will be available.
